# LeadDesk Mini

A full-stack Lead Management application built using React, Express.js, Node.js, and MongoDB Atlas.

## Live Demo

Frontend:
https://lead-desk-mini-bay.vercel.app

Backend:
https://leaddesk-mini-wiv8.onrender.com

GitHub:
https://github.com/abhass450-code/LeadDesk-Mini

## Features

- Public Lead Capture Form
- Client-side Validation
- Server-side Validation
- MongoDB Atlas Database
- Admin Dashboard
- Search Leads
- Update Lead Status (New, Contacted, Closed)
- Responsive UI

## Tech Stack

Frontend
- React
- Vite
- Axios

Backend
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose

Deployment
- Vercel
- Render

## Installation

### Client

```bash
cd client
npm install
npm run dev
```

### Server

```bash
cd server
npm install
npm run dev
```

## Environment Variables

Create a `.env` file inside the server folder.

```
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret
PORT=5000
```
